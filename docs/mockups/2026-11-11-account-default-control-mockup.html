Account default program for new hires (OC-F12 control)

Hyperion Legacy 0.14.0, Wiring WR-10, the control half of OC-F12, for your sign-off before any build. Your answers so far: "Account-wide defaults" (the account default is given to newly hired members), "Merge with built-in" (2026-11-10) and "Built-in first" (the merge order). Names and programs are samples: ship Wayfarer, team Alpha, Security members Okafor (Decapitate), Reyes (the built-in default) and Lindqvist (Custom). The preset titles, rule labels and the merge are the game's own.

4. Your calls

  1. Layout: A (a "Set for new hires" row with the preset actions, a one-line status with Clear) or B (a "New Security hires" card with the merged rules spelled out)?
  2. Button words. Drawn: "Set for new hires" and "Clear" (A); "Use Okafor's program" and "Back to built-in" (B). Keep, or your words?
  3. The Balanced program (engine rule, not decided). A stored Balanced program means "nothing set", so it cannot be a hire default today. Options: (a) keep the rule and disable Set for Balanced with that reason, as drawn; (b) change the engine so Balanced can be chosen (a stored marker for "nothing set"; a small save change).
  4. An empty program. Setting a program with no rules gives hires only the built-in support rules and no attack. Allow with the warning (drawn), or block it?
  5. Clear: the Security half only, or the whole pair? The stored Science half is never read by a hire, but a changed one keeps today's notice showing on old saves. Proposal: Clear puts both halves back to the fresh pair.
  6. Existing members. The engine changes only new hires (your "given to newly hired members"). Copy to squad already covers a squad. Leave it there, or add "also give to everyone already hired"? (Not in the engine; new work.)
