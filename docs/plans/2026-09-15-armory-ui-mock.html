The Armory

How it works (annotations)

  • 25 loadouts, flat. Spend them on any ship type you like; more come from talents. The count is derived, never hardcoded.
  • Each loadout is pinned to a ship type when created (the chip). That sets exactly which slots it has, so you can never over-arm a hull, an unfilled hardpoint just stays Empty.
  • Install pulls from your rolled systems. Install / Swap opens a picker of compatible rolled-pool systems; committing one moves it INTO the loadout (out of the warehouse). Clearing a loadout returns its systems to the pool.
  • Check out to a ship = equip that ship. A loadout is checked out to at most one ship at a time; that ship flies what the loadout holds. A "Universal" loadout is spec-agnostic, for challenge runs.
  • Favorite (★) and Lock (🔒) ride the systems, set on the rolled pool: favorite sorts to the top, lock prevents salvage / sell / destroy. A locked loadout's systems are protected too.
  • No separate storage bin. Committed systems are visible by browsing loadouts; the loadouts ARE the storage.
