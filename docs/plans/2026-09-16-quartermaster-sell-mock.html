Quartermaster · Sell tab

The reserved Sell sub-tab, made real. It is built to SCALE to "sell pretty much anything you want" later, but in 0.13.6 only DEPRECATED stock is flagged sellable, so today the shelf holds one line: Deuterium Ice, orphaned by the fuel-to-reach change. Value is derived from what the item was worth (1 ice = 2 fuel × 20 cr = 40 cr/unit).

Requisition stays a fixed floor-dispenser (same baseline for every ship / ground crew, nothing to expand). Sell is the growable catalog. Purchase and a later Donation counter sit as honest locked markers. Below: the live 0.13.6 state, the empty state, how it scales later, and mobile.

One category shelf, one row. The retired tag explains WHY it is sellable now; the row carries a quantity stepper (sell some) plus Max (sell all of it), a live row total, and a Sell button. The wallet bar shows credits and updates as you sell.

What I would build for 0.13.6

  • Data: an optional sellValue (credits/unit) on the item def. An item is sellable iff it has one. Only Deuterium Ice gets it now (= 40, derived + documented), so the shelf is deprecated-only.
  • Row interaction: a quantity stepper + Max (sell some or all of one item), a live row total, per-row Sell, and a shelf-level "Sell all deprecated" convenience. Confirm reuses the existing Quartermaster confirm preset.
  • Layout: the Warehouse category-shelf idiom you already have (category header + rule, item rows), so it scales to many goods with zero rework, only their defs need a sellValue to appear.
  • Deferred (later): widening "sellable" to non-deprecated goods, real price tuning, Purchase, and the Donation counter, each its own decision. This mock shows those as locked / preview so the seam is visible without committing scope.
