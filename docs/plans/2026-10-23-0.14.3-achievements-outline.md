# 0.14.3 "Achievements": scope outline (draft for later brainstorming)

Status: OUTLINE (2026-10-23). Not designed yet; nothing built. Grown out of the 0.13.11 / 0.13.11.1 prototypes.

## User direction (verbatim, 2026-10-23)

"Also. I think that we should have a plan for 0.14.3. Because we've already started it in this little patch of fun."
Scope pick (all four): main-game achievements, theme builder, minigame rewards pay out, codes and giveaways, with:
"The actual balancing of those systems will come in the 0.16.0 patch. But we want the actual system to be wired in, so
if we did add a bonus to it, it would function. Especially referencing the third one for the pay outs."
Then: "Achievements." (the release's headline).

## Principle

Build every SYSTEM fully wired so any bonus added to it measurably acts (the user's "everything wired" and "wired is
not enough, malfunctioning is a bug" rules); keep the NUMBERS placeholder-safe and [PROVISIONAL] for the 0.16.0 balance
pass. Payouts especially must work end to end.

## The four pieces

1. Main-game achievements (headline). The full system the minigame popup prototyped (0.13.11.1,
   docs/plans/2026-10-23-hotfix-0.13.11.1-design.md section 5): an achievements list with progress, hidden and
   progressive achievements, rewards, and the reusable popup across the whole game. Related: the 0.14.0 completion
   tracking system (designed, chat-event ledger) and the Home "Achievements" tab that today reads "coming soon".
2. Theme builder (moved here from 0.14.2's idea list; 0.14.2 keeps the desktop layout pass): presets (Default,
   Starfall and future unlocks), Manual mode with unlockable theme STYLES (wash, edges, one sweep, wash plus shine) and
   unlockable COLORS, Color 1 / Color 2 with per-color gradient stops, the dark-color readability guard. Source:
   docs/plans/2026-10-22-roadmap-and-release-gates.md (0.14.2 theme builder and presets ideas) and the 0.13.11.1 build.
   The e10,000,000 minigame reward becomes the wash plus shine STYLE unlock.
3. Minigame rewards pay out: the "record now, pay later" promise (0.13.11 answer 8): every recorded minigame milestone
   pays its main-game reward, with back pay for milestones reached before 0.14.3; the relic boosts link (R2-10) if it
   did not ship in 0.14.0; amounts placeholder, balanced in 0.16.0; must work end to end.
4. Codes and giveaways: a real gift-code pipeline on the 0.14.1 online base (server-validated, per-account
   redemption, timed event codes, the SUPERDUPERLEET style messages and the 40 joke lines kept).

## Dependencies

0.14.1 online (accounts, server clock, server-side code validation) lands first. The trusted-time module (0.13.11.1)
switches to the server clock there.

## Open (for the brainstorm)

Achievement categories and count; which achievements pay what kind of reward; how hidden achievements are hinted; how
the theme unlocks tie to achievements; the back-pay rules for minigame milestones; code types (one-time, per-event,
per-account).
