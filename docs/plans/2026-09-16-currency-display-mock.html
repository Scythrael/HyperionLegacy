Currency Display Options

Pick which currencies show on the header (chosen in Options), up to ~4, and the space splits evenly between them. Below are three desktop treatments at 1 / 2 / 3 / 4 selected plus the empty state, then the mobile row. Compare and pick a direction (or mix).

All use the same currency PILL (glyph + value, name tag on hover/where room allows). The only difference is HOW the selected pills are arranged in the header.

Variant A · Dynamic grid (in the current resources slot)

Keeps the resources box the same size where the 2 currencies used to sit; a grid reflows by count: 1 = full, 2 = side by side, 3 = one full + a pair, 4 = 2×2. Most compact, no new header height, but values get tight at 4.

My read

Variant C (the glowing currencies band) is the one I'd lean toward: it never crams the header slot, scales to 4 without values going tight, gives text room, and the empty state collapses to one slim placeholder line instead of a big hole. Variant A is the most space-frugal (no extra height) if you want to keep the header exactly as tall as it is now. Variant B is the cleanest per-pill but grows the header most. All three are the same underlying pill + Options-based selection, so we can even ship one and switch later. This is deferred to the nitpick phase regardless; just here to pick the direction.
