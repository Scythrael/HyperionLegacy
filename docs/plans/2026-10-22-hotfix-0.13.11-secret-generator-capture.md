## User request (verbatim, 2026-10-22)

"Also, I have a request for a special "hotfix" that releases as 0.13.11."

"A new section of the settings menu (this will allow for special gifts, giveaways, etc). But for this instance, it will
provide a secret game.

Remember the original iteration of the game? A stack of generators that made big numbers? I want a version of that to
come back. You open the options menu, you click "enter code" and that will bring up a window with 2 code entry options.
You either enter in an actual code and hit redeem, and it will give you a gift or something. But then there's a button
for "combo input". When you click that, you enter the Konami code. You know the one. "Up, Up, Down, Down, Left, Right,
Left, Right, B, A, Select, Start", but in our case, it'd be a bit different. Select would be right shift. Start would be
the main enter button.

Then the background blurs, and that generator game comes up over the rest of the game while it plays in the
background."

## Recon (verified in git)

- The original game is the 2026-07-02 prototype `66687f3` "closed-form generator stack, tier 1 prestige, versioned
  saves". MODULES: Mining Laser (Common Ore, base 1/s, cost 10, x1.15), Refinery (Refined Ingots, 0.4/s, 60, x1.17),
  Fabricator (Components, 0.12/s, 400, x1.2), Synthesizer (Alloys, 0.04/s, 2500, x1.22, gated by Alloy Synthesis
  research). Specializations (+25% per resource), a small skill tree, prestige. Retired 2026-07-06 (`ddf3cfa`, `f3a330b`,
  `e15a668`). Last full model before removal: `git show ddf3cfa^:src/lib/game/model.ts`.
- Current settings: the gear opens the System modal; its "Settings" tab (key `options`) has sub-tabs UI, Gameplay,
  Confirmations, Save Data (`OPTIONS_TABS` in App.svelte).

## USER ANSWERS (2026-10-22), round 1

1. Connection to the main game: "Standalone now with later rewards, but yes. Let's keep milestones in there for
   rewards, but they won't be infinite. That or the rewards will be logarithmic. Something short and sweet that has an
   end. Let's bring that back, but please add more to it. Let's add additional features to it. More unlocks. More
   multipliers. We want the numbers to get ridiculously huge on there. The regular game will have huge numbers as well
   (I could foresee some ships getting well up into the quadrillions or quintillions of hit points, but the balancing
   pass will determine just how crazy we get)."
2. Version: "Original, expanded. But let's make sure the layout matches the current game's theming, etc."
3. Phones: "On-screen combo pad" (the Combo input window shows arrow, B, A, Select and Start buttons on every device;
   keyboard also works on desktop).

Note for 0.14.0 balancing (not this hotfix): the main game may reach quadrillions to quintillions of ship HP; the
balancing pass decides how far. Number formatting must handle that range.

## USER ANSWERS (2026-10-22), round 2

4. What ends: "Finale, then free play" (a last big unlock beats the secret game and pays the final reward; play can
   continue after for bigger numbers, with no more rewards).
5. Length to the finale: "A few days" (check in now and then over 3 to 5 days).
6. Offline: "Always runs" (keeps producing while the overlay is closed and while the game is closed, like the main
   game).
7. Big numbers: "Suffixes, then scientific" (K to Oc as today, then 1.23e30 style past the named tiers). Note:
   `break_infinity.js` is already a dependency (format.ts), so the range is not a problem.

8. Milestones in 0.13.11: "Record now, pay later" (tracked and saved now; when a later patch adds main-game rewards, everything already reached pays out then, back pay). User-chosen exception to the no-placeholder rule.
9. Reopen: "Combo every time" (the combo is the only way in, every time; no shortcut button).
10. Gift codes: "Box only, no codes yet" (the redeem box works and says a code is not recognized; real codes and gifts come in later patches).

## USER ANSWERS (2026-10-22), round 4

11. Structure: "Cascade (Recommended)" (each generator builds the one below it: Synthesizers make Fabricators, Fabricators make Refineries, Refineries make Mining Lasers, Lasers make Ore; Ore buys everything).
12. Prestige: "Two layers" (a small reset for a quick multiplier, and a bigger one later that unlocks new generators and upgrades).
13. Finale: "Reach e7777777 is the goal. A nice round spam of my favorite number." (1e7,777,777 Ore; free play continues after.)
