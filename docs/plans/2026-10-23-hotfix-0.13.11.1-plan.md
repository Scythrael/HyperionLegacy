**Goal:** Ship the first real gift code (SUPERDUPERLEET, 1,337 credits, once per account, with 40 tracked joke lines and the Endless Greed achievement), a Help / Minigames / Settings header block in place of the gear, a roomier minigame (Upgrades tab with four capped e1,000,000 upgrades, Stats and Help views, hidden milestones), a reusable achievement popup, and the Starfall theme as the e10,000,000 prize.

**Tech Stack:** Svelte 5 (legacy, non-runes syntax as in the rest of the repo), TypeScript, break_infinity.js `Decimal`, Vitest.

## Review Focus

The five failure modes most likely to bite a real player, each pinned by a test in the owning task:

1. **A 0.13.11 player's secret save stops loading** (the new fields are missing from every existing save, and a strict loader would throw them away for a fresh game). Task 2: `a 0.13.11 save loads with every new field defaulted` deserializes a save written in the exact 0.13.11 shape and checks Ore, milestones and counts survive, upgrades are 0, and a played save counts as found.
2. **The 1,337 credits pay twice** (a double click, re-entering the code, a reload). Task 1: `pays once per account` redeems twice and asserts the second call returns the same state reference with no credit change; the redeemed id survives a save round trip.
3. **The main save loses or garbles the new fields, or Delete Save leaves them behind** (Starfall still unlocked on a fresh save). Task 1: `round-trips through serialize, deserialize and migrate` and `a fresh save has none of them`; Task 9 wiring: `resetSave replaces the state with freshState`.
4. **Pacing before e1,000,000 moves** for players already part way through (an upgrade effect that is not exactly 1 at level 0, a changed step order). Task 3 goldens (captured before any engine edit): fixed states stepped for fixed times must serialize the 0.13.11 fields byte-identically; Task 4: the steady player still lands in every 0.13.11 band.
5. **Starfall is hard to read** on some accent or in the color-blind palette, or shows after its unlock is gone. Task 7: `washShine clears AA` sweeps every text token and accent over both gradient stops for panels, buttons and primary buttons, with and without the cbsafe palette; `the style only applies while unlocked` checks the effective style falls back to Default without the account flag.

## Decisions the builder made (within the design)

- **Main-save field names** (neutral, no "secret" in model.ts): `redeemedGifts?: string[]` (gift ids, never the code), `seenCodeLines?: number[]` (1 to 40), `endlessGreedAt?: number` (the Endless Greed flag, as the date it was earned), `unlockedThemeStyles?: string[]` (the Starfall unlock mirror, `["washShine"]`).
- **Minigame "found" lives in the secret save** (`found`, `foundAt`), so Delete Save (which wipes the secret save) re-hides the Minigames button. A 0.13.11 save that shows any play (anything bought, any prestige) counts as found, with `foundAt` from its earliest milestone if any.
- **The re-entry streak** (third consecutive re-entry adds a joke line) is session state in the Enter Code window's module scope: closing and reopening the window keeps it; any other result resets it. Lines are picked uniformly at random among the 39 not shown last.
- **Upgrade prices are effective-exponent thresholds.** Above the finale one effective unit is thousands of raw exponent units, so paying the price barely dents Ore; the price is in practice the point on the Ore climb where the level opens. Kept as a real Ore price (Buy 1, Buy 10, Max) so it reads like the rest of the game.
- **The four upgrade effects are rate boosters, not gain boosters.** Measured on the steady player's e1,000,000 state: anything that raises prestige GAINS (Dream Point power on gains, Captain and Augment gains) makes the automatic prestiges fire at once and reset a run that took weeks, so the best Ore stalls for weeks. So: Overclock Overclocker makes each Overclock level count as (1 + step x level) levels; Tenfold Tuner adds step x level to the ten bonus factor; Captain's Compound counts Captain and Augment Points as (1 + step x level) times as many for the speed multiplier; Lucid Dreaming lets Dream Points speed the stack too, x (1 + DP)^(step x level). [PROPOSAL] effect wording: "Your Captain and Augment Points count as more" and "Dream Points also speed up the whole stack".
- **Pacing sim, six-month stretch:** once e1,000,000 is reached the simulated offline gaps run as coarse steps (no exact window) so half a year runs in about a minute; sessions stay live 1-second play. Measured against the shipping catch-up (results section).
- **The freed main-view space** (goal bar and run bar removed) is simply not drawn, so the panel fits one screen; nothing new goes there.
- **Milestone visibility:** the Ore chain googol, e1,000, e100,000, e777,777, e1,000,000, e10,000,000 appears one step at a time (googol from the start); first Captain and Overclock 10,000 from the start; first Fleet after the first Captain; first Prestigeception and all skills after the first Fleet; the Singularity Engine once its tier unlocks.
