**Hyperion Legacy 0.13.11.5** is live.

Having the game open in two tabs can no longer erase your progress. Before, the older tab could save over the newer one without any warning. Now the game runs in the tab you opened most recently: the older tab hands over all its progress, stops, and tells you so. Export Save also saves first, so the file holds your latest progress. Your save carries over untouched.

If you still have the game open in an older tab from before this update, reload or close it.

Full patch notes: <https://crystalisoft.com/game/hl/patch-notes>
