**Hyperion Legacy 0.13.11.6** is live.

One more fix for having the game open in more than one tab. Phones and battery savers pause game tabs left in the background. If you opened the game in a new tab, played, closed that tab, and then went back to the paused one, it could save its older progress over the newer tab's. A tab that has been replaced now stays stopped even when it wakes up later. Your save carries over untouched.

Full patch notes: <https://crystalisoft.com/game/hl/patch-notes>
