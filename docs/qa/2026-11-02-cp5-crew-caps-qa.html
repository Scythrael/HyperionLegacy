Builder notes (CP-5, 2026-11-02)

  1. The totals are yours; the mixes are provisional. Eir 900 and Orion / Aurora 750 are your OC-5 answer. The exact division weights (for example the Eir's 77 / 189 / 279 / 234 / 81 / 40, the Battleship's Security 56 and Engineering 48, the Carrier's Flight Deck 56) are a first pass that follows the leans you approved; the Aurora's Science cap is 270.
  2. No division ever shrinks (your 2026-11-02 answer). Every division on every hull keeps at least the seats it had, at every rank, with or without a quarters module. On the Aurora, Battleship and Carrier the total is unchanged, so the lean is extra division seats: the leaning division can take more of the same total. No existing ship turns "Over cap" from the new caps.
  3. Notables count. The header, each division's "N / cap" and the fill bar count notables aboard, the same count every add uses (234 bulk + 1 notable Medical on the Eir reads 235 / 234).
  4. Roster pins. A pin already aboard now holds its seat before any other pin is placed, so applying a roster can never put a ship over its cap.
  5. A passive Eir grows. An auto-crewed Eir takes up to 150 more crew from the pool on its next fill (worth a patch note line). A ship out on a run takes none until it is home or claimed, as before.
  6. No save step. Old saves load unchanged and no run in flight changes.
