## 1. Craft -> Inspect -> Roll (item lifecycle)
- [ ] Fabricate a system. It arrives as a **blank** (stackable), NOT a finished rolled item. Two of the same recipe **stack**.
- [ ] Open the Fabricator **Inspect** tab. Inspecting a blank **rolls** it into a system with quality/rarity/stats; it lands in the spare bay (Logistics > Ship Equipment).
- [ ] The `?` on **Inspect Blanks** explains blanks; the panel is not cluttered with the old green paragraph.
- [ ] Regression: crafting XP / crafting level still advance from crafting; the craft queue still runs and reserves materials.

## 2. The Armory (loadouts)
- [ ] Create a loadout for a hull type; rename it; delete a different one.
- [ ] Add rolled systems to the loadout; the slot derivation + Battle Rating read correctly.
- [ ] **Check out** the loadout to a ship: the ship equips the whole set in one step.
- [ ] The checked-out ship's own install screen is **locked** (edit happens in the Armory instead).
- [ ] **Check in** frees the ship again.
- [ ] The `?` on **Armory - Loadouts** carries the intro; no green paragraph below the title.
- [ ] Regression (bug fix): try to **salvage / scrap / uninstall** gear that is committed to a loadout, it is **protected** (cannot be lost).

## 6. Favorite and Lock (spare bays)
Two surfaces show the toggles: **Logistics > Ship Equipment** and **Facilities > Salvage Bay**. Both share the selection and both host the controls.
- [ ] In **Ship Equipment**, tap a spare: an **inline** card opens below the grid (not a floating popover) with **Favorite** and **Lock** buttons.
- [ ] **Favorite** a spare: it gains a **star** marker and sorts to the **top of its group**; the button reads "★ Favorited". Un-favoriting drops it back.
- [ ] **Lock** a spare: it gains a **padlock** marker; the button reads "🔒 Locked". A piece can show **both** the star and the padlock.
- [ ] In the **Salvage Bay**, select the locked spare: the **Salvage / Destroy** button is **disabled**, with a "Locked, so nothing can salvage it. Unlock it to salvage." note.
- [ ] **Unlock** it (from either surface): Salvage / Destroy re-enables immediately.
- [ ] Try to **install** a locked spare on a ship (Ships > a ship > Install/Swap): it is **blocked** with a "locked (unlock it in Ship Equipment first)" reason.
- [ ] Try to **commit** a locked spare to an Armory loadout: it is **refused** (nothing happens / not offered).
- [ ] Regression: a merely **favorited** (not locked) spare can still be salvaged, installed, and committed normally, favorite is display-order only.
- [ ] Regression: with auto-salvage rules ON, a **locked** spare is never queued; an unlocked one is subject to the rules as before ("Lock it to keep it." note).
- [ ] **[M]** The Favorite / Lock buttons and their note wrap cleanly; the tile markers are not clipped.
