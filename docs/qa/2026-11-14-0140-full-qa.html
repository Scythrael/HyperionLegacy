Before you start

  • Where: staging only, https://devpreview.crystalisoft.com, on the 0.14.0 build that carries the freeze fix (merge 6f0de0be, fix 3ba8af02). Staging is a preview build, so the System window (the gear) has a Debug tab. There is no ?dev switch: wherever a linked sheet says "?dev Debug", read it as the Debug tab on staging.
  • A fresh save: a new browser profile opened on devpreview. Clearing site data alone is not a reliable reset, so use a new profile (or Settings, Save Data, Delete Save in a profile you do not need).
  • An old save: in the live game, Settings, Save Data, Export Save, and keep that file safe as your backup. Note its size in KB. In a second browser profile open devpreview and use Settings, Save Data, Import Save. The older and longer-played the save, the better: it is what found the freeze.
  • Keep the console open in both profiles for the whole pass. No console errors is part of every section.
  • Changes only: run Part A (sections A0 to A16). Full regression: run Part A, then Part B (R1 to R13). Part B rows tagged "fresh save" are quickest on the fresh profile; everything else can use either.
  • Known issues: rows from the Fable sweep ledger (2026-11-13-fable-sweep-ledger.md) whose fix has not landed carry a chip. The row's text states the behavior you answered for; until the fix lands such a row is expected to fail, so note it and move on instead of re-reporting it.

The columns. 1280 is desktop, 375 is a phone width (or a real phone). A row that only makes sense at one width shows n/a in the other column with a desktop only or phone only tag. A row with one centered box checks rules, not layout: one pass at either width is enough.

Tags: fresh save a new save. needs real save your old (migrated) save. needs device touch, a real phone, or a visual call. light + dark look at it in a light and a dark theme color. Debug tab uses the staging Debug tab.

Status: fixed, verify a ledger finding fixed on the branch. known issue, fix pending you answered the design question (or it is a plain bug); the fix has not landed. known issue, decision pending still on your list of questions. known issue, open a minor finding not yet scheduled. sweep gap a check the Fable sweep said the QA list was missing.
