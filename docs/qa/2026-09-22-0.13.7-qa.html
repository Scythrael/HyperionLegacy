Hardening and fixes folded into this patch (Claude, 2026-09-22)

  1. Cap-safe, all-or-nothing inspection. Following the race-condition concern, inspecting recomputes the free spare-bay space from live state before every mint and is transactional: a batch can never push the bay past its cap (verified live filling to exactly 25/25), and a roll that cannot fit never consumes its blank or burns the roll seed. Covered by 8 new unit tests (inspectBlank.test.ts): cap no-op, clamp-to-free, preserve-non-fitting-blanks, and n-bulk == n-singles determinism.
  2. Honest completion-log wording. A finished craft used to be classified as producing "systems" when it actually deposits an uninspected blank. A new "blanks" completion reward kind makes the Recently-Completed row read "Fabricated, {Blueprint}" with the detail "Uninspected blank" (or "N blanks" for a folded batch). Exact strings pinned by 3 new tests (completionLog.test.ts).
